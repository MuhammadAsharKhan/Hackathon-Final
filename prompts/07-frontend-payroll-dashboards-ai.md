Read prompts/hcm/00-SPEC.md completely (sections 4.5, 4.6, 5, 7, 8), then knowledge.md, theme.md, docs/ARCHITECTURE.md and the shared components. Change client/ and docs only. Follow section 0 of the spec. Match the server routes if they exist, otherwise build to the spec and list mismatches under Known issues.

## Steps
1. Payroll (/payroll, HR and Admin): month picker (not later than the current month), "Create or recalculate draft" button for HR, runs table (month, status badge, employees, gross, deductions, tax, net, finalized by and date). Run detail page (/payroll/:id): totals cards, DataTable of payslips (employee, code, department, eligible days, absent, unpaid, half days, gross, deduction, tax, net), row click opens a Payslip drawer with the full breakdown (earnings, deductions, formula lines in plain text), PDF button. Admin sees "Finalize" with a ConfirmDialog explaining that the month locks; after finalization all edit and recalculate buttons disappear and a "Finalized" banner shows. HR sees the draft banner "Draft, not visible to employees". Handle the 409 and 422 messages.
2. My payslips (/me/payslips): list of finalized payslips (month, gross, deductions, tax, net, PDF button). PDF download uses axios blob with the auth header and a filename; show a spinner on the button and an error toast on failure. Never open the PDF URL directly.
3. Dashboards (/dashboard picks the component by role). All charts use recharts inside ChartCard with a responsive container, readable axes, tooltips, the theme colors, and an empty state when there is no data. FilterBar on top (date range with presets This month, Last 7 days, This year; department select) and a loading skeleton while fetching.
   - Admin dashboard: KPI cards (headcount, attrition YTD, payroll cost this month and total finalized, average salary), bar chart headcount by department, bar chart payroll cost by department, line or bar payroll cost by month, pie or bar gender, bar tenure buckets, average salary by department and by designation tables, audit feed (latest 10 with actor, action, time), the Summarize button.
   - HR dashboard: KPI cards (headcount, present today, on leave today, late today, pending approvals with links to the inbox pages), line chart attendance trend, bar chart absenteeism by department, bar chart leave by type, top 5 late-comers table, leave utilization table, the Summarize button, plus a compact CheckInPanel for HR's own attendance.
   - Employee dashboard (also used by HR as a section called "My day"): CheckInPanel, hours this week vs weekly target as a progress bar, late count this month, leave balance cards, last payslip card with download, latest announcements, an "Ask my assistant" button that opens the assistant panel with focus in the input.
   - SummaryCard component: "Summarize" button calls POST /ai/dashboard-summary with the current filters, shows 3 to 5 bullets with an "AI-generated" badge, shows a small note when fallback is true, loading and error states, disabled while loading, remembers the last result until filters change.
4. Assistant panel (components/ai/AssistantPanel, available on every page for all roles): floating button bottom right (bottom left of the sidebar on mobile is NOT used; keep bottom right and above the safe area), opens a right drawer (full screen under md). Contents: header with title and "AI-generated" label, message list (user bubbles in primary color on the right, assistant bubbles on the left rendered with react-markdown and remark-gfm, no raw HTML), typing indicator, small caption showing which tools were used ("Used: attendance summary"), suggested prompts by role (HR and Admin: "How many active employees do we have?", "Who came late most often this month?", "What is this month's attendance rate?", "Who is on leave today?"; Employee: "How many sick leaves do I have left this year?", "What are the office timings?", "What is my last net pay?"), input with Enter to send and Shift+Enter for a new line, 1000 character limit with counter, disabled while waiting, retry button on failure, friendly messages for 429 ("You reached the hourly limit for the assistant") and 503. Conversation id kept in component state and sessionStorage so the thread survives navigation within the session; "New chat" button. A hook hooks/useAssistant.js holds the state and calls (api/ai.api.js). Reuse the existing chat components from the boilerplate where they fit (MessageBubble, CodeBlock, TypingIndicator) instead of writing new ones.
5. Admin AI keys page keeps working at /admin/ai (menu "AI keys").
6. Polish: consistent spacing, tabular numbers for money (right aligned, thousands separators, PKR prefix via one formatMoney helper in lib/format.js), formatDate and formatTime helpers using the company timezone from /auth/me or settings, accessible chart alternatives (a visually hidden table or aria-label summary per chart).
